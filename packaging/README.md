# PDF-OCR-Picker 使い方

PDF を読み取って「請求書かどうか」を自動で判定し、フォルダに仕分けするツールです。
あわせて、PDF をまとめて印刷するツールも入っています。

---

## ⚠️ 最初に必ずお読みください

この **`pdf-sorter` フォルダは、丸ごとで 1 つのアプリ**です。
中の `.exe` だけをデスクトップなどにコピーすると、次のエラーで起動しません:

> Failed to load Python DLL '…\_internal\python312.dll'.
> LoadLibrary: 指定されたモジュールが見つかりません。

これは、アプリの本体が隣の **`_internal` フォルダ**に入っているためです。

**正しい使い方:**

- `pdf-sorter` フォルダは **丸ごと**好きな場所に置いてください。
- `_internal` フォルダは **消さない・名前を変えない・別の場所に移さない**でください。
- デスクトップから開きたいときは、`.exe` を右クリック →
  **「送る」→「デスクトップ (ショートカットを作成)」** でショートカットを作ってください。
  （`.exe` そのものをコピーしないこと）

---

## 入っているもの

| ファイル | 役割 |
|---|---|
| `pdf-sorter-gui.exe` | 仕分けを試す・調整する画面（**ダブルクリックで起動**） |
| `pdf-print.exe` | PDF をまとめて印刷する画面（**ダブルクリックで起動**） |
| `pdf-sorter.exe` | Power Automate やコマンドから呼ぶ用（コンソール） |
| `rules.yaml` | 判定に使うキーワード一覧（メモ帳で編集できます） |
| `sample.bat` | GUI を使わず仕分けするときのサンプル（下記「GUI を使わずに実行する」） |
| `_internal\` | アプリの本体。**触らないでください** |

---

## 初回起動でこんな画面が出たら

「**Windows によって PC が保護されました**」という青い画面が出ることがあります。
配布元の署名がないアプリのために出るだけで、危険ではありません。
**「詳細情報」→「実行」** で起動できます。

---

## 仕分けを使う（`pdf-sorter-gui.exe`）

1. ダブルクリックで起動します。
2. **読み取るフォルダ**と、**仕分け先フォルダ**を選びます。
3. **「Classify all」** を押すと判定し、次の 3 つに振り分けます:
   - **Match** … 請求書と判定
   - **Review** … 判定が微妙（人の目で確認をおすすめ）
   - **Other** … 請求書ではない
4. どのキーワードが当たってその点数になったのか、画面で理由を確認できます。
5. うまく判定されない取引先があれば、キーワードを足して調整できます（下記）。

---

## 印刷を使う（`pdf-print.exe`）

1. ダブルクリックで起動します。
2. **「Add files...」** で PDF を追加します（「Add folder...」でフォルダ単位も可）。
3. **プリンター**と**部数**を選びます。
4. **「Print」** で印刷開始。途中でやめたいときは **「Stop」**。

※ この印刷ツールは仕分け機能とは独立しています（判定やフォルダ移動は行いません）。

---

## 判定を調整したいとき

`rules.yaml` をメモ帳で開くと、判定に使うキーワードや点数を編集できます。
（`pdf-sorter-gui.exe` の画面からも読み込み・編集・保存ができます）

---

## GUI を使わずに実行する（バッチファイル `.bat`）

GUI を開かずにまとめて仕分けしたいときは、**コンソール版の `pdf-sorter.exe`** に
オプションを付けて呼び出します。毎回手で打つ代わりに、**同じフォルダに置いた
`.bat` ファイルにオプションを書いてダブルクリック**するのが簡単です。

このフォルダに **`sample.bat`** を同梱しています。使い方は 3 ステップ:

1. `sample.bat` を右クリック →「編集」（メモ帳で開きます）。
2. 先頭のほうにある 2 行を、自分のフォルダに書き換える:
   ```
   set "INPUT=C:\pdf\in"     ← 読み取り元（PDF が入っているフォルダ）
   set "OUTPUT=C:\pdf\out"   ← 仕分け先（Match / Review / Other が作られます）
   ```
3. 保存して閉じ、`sample.bat` を**ダブルクリック**。

> `sample.bat` は `pdf-sorter.exe` と**同じフォルダ**にある前提です（`%~dp0` という
> 書き方で「自分と同じ場所の exe」を呼ぶため、フォルダごと移動しても動きます）。

書き換えずに中身を直接コマンドで書くとこうなります:

```
pdf-sorter.exe batch "C:\pdf\in" --move-to "C:\pdf\out"
```

よく使うオプション:

| オプション | はたらき |
|---|---|
| `--dry-run` | 実際には動かさず、どう仕分けるかだけ確認する |
| `--recursive` | 読み取り元のサブフォルダも対象にする |
| `--out result.jsonl` | 処理結果をログファイルに残す |
| `--pages 0` | 各 PDF を全ページ読む（既定は 1 ページ目のみ） |

### 1 ファイルだけ判定する / Power Automate から使う

`classify` は 1 ファイルを判定し、**終了コード**で結果を返します
（Power Automate から呼ぶときに便利です）:

```
pdf-sorter.exe classify "C:\pdf\in\example.pdf"
```

| 終了コード | 意味 |
|---|---|
| 0 | 請求書 |
| 1 | 請求書ではない |
| 2 | 要確認 |
| 9 | エラー |

※ Power Automate では、フルパスで `…\pdf-sorter\pdf-sorter.exe` を指定してください。

---

## 困ったとき

- **起動しない / DLL のエラーが出る** → `.exe` を単体でコピーしていませんか？ **フォルダごと**置いてください。
- **`_internal` を消してしまった** → もう一度 zip を展開し直してください（アプリの本体です）。
- バージョンは `pdf-sorter.exe --version` で確認できます。
